# Primeiro Projeto Fullstack

Projeto de estudo conectando frontend React com backend Node.js/Express.

## Tecnologias

**Frontend**
- React
- TypeScript
- Vite
- Axios

**Backend**
- Node.js
- Express
- TypeScript

## Como rodar

**Backend**
```bash
cd backend-api
npm install
npx ts-node index.ts
```

**Frontend**
```bash
cd primeiro-projeto-vite
npm install
npm run dev
```

## Rotas da API

- `GET /hello` — retorna texto "HELLO WORLD"
- `GET /hello-json` — retorna JSON `{"hello": "world"}`
